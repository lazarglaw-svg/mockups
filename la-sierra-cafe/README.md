# La Sierra Café — HTML/CSS

Dieses Paket enthält die komplette statische Version der Website:

- `index.html` — Inhalt und Seitenstruktur
- `styles.css` — vollständiges Design inklusive Desktop- und Mobile-Ansicht
- `images/` — alle verwendeten Bilder
- `fonts/` — lokal eingebundene Schriften

## In Codex öffnen

1. ZIP-Datei entpacken.
2. Den Ordner `La-Sierra-Cafe-HTML` in Codex öffnen.
3. Codex mitteilen: „Öffne dieses Projekt und verwende `index.html` als Startseite. Behalte das bestehende Design bei.“

Für eine einfache lokale Vorschau kann `index.html` direkt im Browser geöffnet werden. Bei einem lokalen Webserver muss `index.html` aus dem Projektordner ausgeliefert werden.

Die Schreibschrift ist Pinyon Script. Alle Bild- und Schriftdateien werden lokal geladen; es sind keine externen CDN-Abhängigkeiten erforderlich.
